# Better bank
## Description
This is very similar to my [Bank project](https://github.com/evg4/Bank) but I added an openingBalance argument to the BankAccount class just to continue practising with a slightly different set up. Unlike the first version, this one doesn't have tests and doesn't use an Interface.

## How to use

``` bash
# Requirements: Java 21
java -version

# Clone the repo
git clone https://github.com/evg4/BetterBank.git
cd BetterBank

# Build the project
./gradlew build

# Run the app
./gradlew run

```
